# Prompt & Context Engineering Field Guide

A standalone, static website. It has no build step or server-side dependencies.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example, `prompt-context-engineering-guide`).
2. Upload `index.html` and `.nojekyll` from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. GitHub will show the public site URL in the Pages settings.

The website and repository contents will be public on GitHub Free. The current site is a static HTML page, so no framework, build command, or environment variables are needed.
